Detailed Description

Square 2D convolution.

The input is NCHW. Weights are exposed as weights and bias. inertia_val is the scale applied to a weight gradient already stored from an earlier backward; zero overwrites it. Forward and both backward algorithms come from cuDNN's search the first time a shape is seen.
