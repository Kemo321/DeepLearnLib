Detailed Description

Dense float32 array with an explicit shape and device.

The constructor that takes an existing shared_ptr builds a view: the allocation is shared and freed when the last tensor that references it dies. Elementwise operators that return a tensor allocate a result. Methods whose names end in _ write into *this. GPU math throws if an operand is on the CPU, if the shapes cannot be combined, or if a pointer is null.
