Detailed Description

Affine map y = x W + b for a batch of row vectors.

x is [batch, input_size], W is [input_size, output_size], and b is added to every row. The product is written into a buffer reused for the same shape. Parameters are exposed as weights and bias. inertia_val is the cuBLAS beta used when accumulating the weight gradient, so a value of zero overwrites the previous gradient.
