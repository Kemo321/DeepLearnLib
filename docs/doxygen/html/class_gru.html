Detailed Description

GRU that returns only the hidden state after the last time step.

The input is [batch, time, features]. The output is [batch, hidden_size]. The initial hidden state is zero. Parameters are one cuDNN weight-space tensor named weight_space, updated with the same SGD rule as the other layers. For a hidden size of at most 128 the forward path uses CUDNN_RNN_ALGO_PERSIST_STATIC_SMALL_H. Arithmetic stays on cuDNN's default math mode so the gate order matches LibTorch. eval() switches cuDNN to its inference path.
