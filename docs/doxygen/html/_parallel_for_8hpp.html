◆ parallel_worker_count()

auto dl::parallel_worker_count ( int work_items) -> int
inline

How many workers to spawn for work_items independent jobs.

The count is at most 16, at most the hardware concurrency, and at most work_items. One item or fewer uses one worker. Unknown hardware concurrency is treated as 8.

◆ parallel_for()

template<typename Fn>
auto dl::parallel_for ( int count,
Fn && fn ) -> void

Invoke fn once for every index in [0, count).

Work is striped across workers. The first exception thrown by a worker is rethrown after the remaining workers have finished. fn must be safe to call concurrently on distinct indices.
