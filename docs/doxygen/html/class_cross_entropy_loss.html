Detailed Description

Mean cross-entropy of logits against one-hot targets.

Both tensors are rank-2, shaped [batch, classes], and must live on the GPU. Softmax subtracts the row maximum. Probabilities passed to the logarithm are clamped away from zero. The returned gradient is (probability - target) / batch.
