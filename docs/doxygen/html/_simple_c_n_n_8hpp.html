Detailed Description

Two-block convolution network used for MNIST and CIFAR-10.

The stack is fixed: Conv2d 3x3 (16, pad 1), Leaky ReLU 0.1, MaxPool 2x2, Conv2d 3x3 (32, pad 1), Leaky ReLU 0.1, MaxPool 2x2, Flatten, FullyConnected. Two pools divide the spatial side by four, so a 28x28 input yields 1568 features and a 32x32 input yields 2048.
