Detailed Description

One stage of a network.

Subclasses with parameters expose them as views named weights and bias, or weight_space for GRU. Layers without parameters (Leaky ReLU, max pooling, flatten) leave step empty.

The training program writes learning_rate, momentum, weight_decay, and gradient_clip before an epoch. Layers do not read the experiment file.

◆ step()

virtual void Layer::step ( cudaStream_t stream = 0)

Apply SGD to the parameters stored by the matching backward.

Weight decay and optional clipping happen inside the update kernel. The default implementation is a no-op for layers without parameters.

Reimplemented in Conv2d, FullyConnected, and Gru.
