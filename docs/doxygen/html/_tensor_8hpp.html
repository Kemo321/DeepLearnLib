Detailed Description

Float32 tensor, CUDA status checks, and the process-wide cuBLAS handle.

A tensor is a shape plus a single allocation. Copying is deleted so a large block is not duplicated by accident. A view is another tensor that shares the allocation and may use a different shape. Training tensors live on the GPU. The host is used to load a batch, read a loss or logits, and save weights.
