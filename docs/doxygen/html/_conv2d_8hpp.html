Detailed Description

2D convolution through cuDNN, plus the descriptor wrappers it needs.

Bias is applied in the same cuDNN call as the convolution, with an identity activation. If cuDNN rejects that fused call, the convolution and the bias addition run as two calls. Leaky ReLU stays a separate layer. Algorithms are chosen on the first batch of a given shape and reused until the shape changes.
