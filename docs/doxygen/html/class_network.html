Detailed Description

Forward evaluation and checkpoint I/O for a list of layers.

forward does not compute a loss and does not update weights, so the same object serves training and the forward-latency benchmark. The loss and the SGD step live in the training program: forward, loss, backward from the last layer to the first, then Layer::step on each layer.

A checkpoint is a host-endian binary file with no magic number. It stores the layer count, then for each layer the parameter count and, for every parameter, the name, rank, dimensions, and row-major float32 values. Optimizer state and the epoch number are not stored. load requires a network with the same number of layers.
